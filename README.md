# amal.saeed()

My personal site. ✿

Built with **Next.js**, **Tailwind CSS**, and **TypeScript**, deployed on Vercel. Dark mode by default, a typing terminal, pop-able stickers, and maybe a hidden easter egg or two.

## Run it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/page.tsx`: all the content (work, projects, about, contact)
- `app/globals.css`: theme colors, sticker styles, animations
- `components/`: the terminal, theme toggle, confetti stickers, copy-email button, and other small interactive bits
